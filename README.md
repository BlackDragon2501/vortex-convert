# Vórtex Convert

**Convierte tus imágenes, sin límites.** App de Vortex Company, parte de la suite Vórtex Studio.

Convertidor de formatos de imagen por lote con la API de Canvas (`toBlob`), sin servidor.

- Formatos de salida: **PNG**, **JPG** y **WebP**.
- Control de calidad 30–100% para JPG/WebP, redimensionado opcional (máximo lado hasta 4096 px) y color de fondo para la transparencia al pasar a JPG.
- Peso **antes → después** con porcentaje de ahorro por imagen y total del lote.
- Descarga individual o de todo el lote.

## Características

- Gratis, sin anuncios y sin rastreo.
- 100% local: las imágenes no se suben a ningún servidor.
- Compatible con PC y móvil.
